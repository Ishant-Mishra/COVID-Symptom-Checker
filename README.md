# COVID Symptom Checker — Educational ML Experiment

This project explores a Decision Tree classification workflow using symptom-related features to predict a label from a **synthetic educational dataset**. It is intended to demonstrate machine-learning workflow steps, not to provide medical guidance.

## Project Contents

- `COVID_Symptom_Checker (1).ipynb` — notebook with data preparation, model training, feature-importance exploration, and decision-tree visualization.
- `covid_symptom_data.csv` — dataset used by the notebook.
- `README.md` — project overview and limitations.

## Workflow

1. Load and inspect the symptom dataset.
2. Handle missing values and examine possible outliers.
3. Prepare symptom features for model training.
4. Train a Decision Tree classifier.
5. Review feature importance and visualize the resulting tree.

Run the notebook from top to bottom and verify the data and metric definitions before interpreting results. Install the Python packages imported by the notebook in your own virtual environment.

## Important Medical Disclaimer

**This model is not a diagnostic tool and must not be used to make healthcare decisions.** The data is synthetic and does not establish clinical accuracy, real-world generalization, or medical validity. A prediction from this notebook cannot confirm or rule out COVID-19. For health concerns, consult a qualified healthcare professional and follow current public-health guidance.
